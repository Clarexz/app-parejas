# Fase 0 — Cimientos

Parche de la Fase 0: corrige el chequeo de conexión con el servidor. En la v0.0.1 podía salir
"Servidor: con problemas ⚠️" aunque todo estuviera bien, porque la raíz de la API REST solo
responde completa a la llave de administrador.

## Cómo instalar

1. Desde el celular, abre este release en GitHub y descarga `app-parejas-v0.0.2.apk`.
2. Ábrelo: se instala encima de la v0.0.1 (misma firma).

## Qué probar

- La app abre y muestra **App Parejas** y la versión **0.0.2**.
- El tema **claro/oscuro sigue al del sistema**.
- Aparece **"Servidor: conectado ✅"**. Si sale otra cosa, mándame una captura.
