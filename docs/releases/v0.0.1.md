# Fase 0 — Cimientos

Primer APK de **App Parejas**. Es la base técnica: la app abre, se conecta a tu servidor y
sirve para comprobar que todo el pipeline (CI, firma, releases) funciona. Todavía no hay
funciones de pareja; eso empieza en las siguientes fases.

## Requisitos previos

- El servidor está levantado: el prompt **S1** ya se aplicó en el VPS y el reporte salió bien.
- Los secretos de GitHub están cargados (Settings → Secrets and variables → Actions):
  `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`,
  `ANDROID_KEY_PASSWORD`, `EXPO_PUBLIC_SUPABASE_URL` y `EXPO_PUBLIC_SUPABASE_ANON_KEY`.

## Cómo instalar

1. Desde el celular, abre este release en GitHub (app de GitHub o navegador con tu sesión iniciada).
2. Descarga el archivo `app-parejas-v0.0.1.apk`.
3. Ábrelo. La primera vez Android te pedirá permitir **instalar apps desconocidas** para el
   navegador o la app de GitHub que usaste: acéptalo.
4. Las siguientes versiones se instalan encima de esta sin perder la sesión (misma firma).

## Qué probar

- La app abre sin cerrarse.
- Se ve el título **App Parejas**.
- Se muestra la versión **v0.0.1**.
- El tema **claro/oscuro sigue al del sistema** (cámbialo en los ajustes del celular y vuelve a la app).
- Aparece **"Servidor: conectado ✅"**. Si sale otra cosa, avísame con una captura.
