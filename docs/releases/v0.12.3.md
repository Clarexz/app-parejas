# Fase 12 — Aviso de versión nueva

Desde esta versión ya no hace falta buscar el APK en GitHub:

- Al abrir la app, si hay una versión más nueva, sale una tarjeta en **Inicio** con **Descargar**.
  Se baja en el navegador; al terminar, ábrela y dale a **Actualizar**. No se borra nada.
- **Luego** la esconde un día.
- También puedes revisar a mano en **Más → Buscar versión nueva**.

Esta versión se instala **a mano por última vez** (desde este release). Las siguientes llegan solas.

## Antes de instalar

No toca el servidor: se puede instalar directo.

## Qué probar

- [ ] **Más → Buscar versión nueva** muestra `v0.12.3` y, al tocarlo, dice "Estás al día".
- [ ] Cuando salga la siguiente versión: la tarjeta aparece en Inicio, **Descargar** abre la
      descarga, el APK se instala encima y la sesión sigue abierta.
- [ ] **Luego** esconde la tarjeta y no vuelve a salir al reabrir la app ese mismo día.
